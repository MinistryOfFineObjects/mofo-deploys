# MOFO deploy log

**MOFO (Ministry of Fine Objects)** is a B2B sourcing platform for contract-grade
furniture, lighting and decor. It helps trade buyers find and source furniture for
commercial projects.

This repository is a public record of **every production deploy** of MOFO.
Each deploy has one commit, dated to the moment it went live, and one entry in
[CHANGELOG.md](CHANGELOG.md).

## How to read the changelog

- Entries are listed newest first.
- Times are US Eastern (ET).
- Summaries describe what changed for people using MOFO, in plain English.
  They deliberately leave out implementation details.
- Entries from July 25 to November 3, 2026 were backfilled from the deploy
  history, so they just say "Deployed to production".
